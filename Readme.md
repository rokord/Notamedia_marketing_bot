# 📘 Telegram Quiz Bot

Интерактивный Telegram-бот для проведения квиз-диагностики готовности компании к выходу на международные рынки.
Бот задаёт 21 вопрос, формирует рекомендации, отправляет результаты в админ-чат и логирует их.

## 🚀 Возможности
- Квиз из 21 вопроса с кнопками
- Подсчёт баллов
- Рекомендации по блокам
- Отправка итогов в Telegram-группу
- Логи завершённых и незавершённых опросов
- Автозапуск как systemd-сервис
